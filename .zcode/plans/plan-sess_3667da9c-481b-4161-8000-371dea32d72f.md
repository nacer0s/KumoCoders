## Plan: Admin Direct Notifications + Polls in Feed

### Feature 1: Admin Direct Notification

**Server** — New endpoint `POST /api/community/admin/notify`
- Requires admin role
- Accepts `{ username, message, link? }`
- Resolves username to user ID, creates a `system` type notification

**Admin UI** — New page `apps/admin/src/pages/SendNotification.jsx`
- Username input + "Lookup" button to verify the user exists
- Message textarea
- Optional link input
- Submit + success/error feedback

**Admin App.jsx** — Import SendNotification, add route `/admin/send-notification`, case in switch  
**AdminLayout.jsx** — Add "Notifications" nav item (after "Community")

### Feature 2: Polls in Feed

**Server** — Add `CommunityPoll.findByPostIds(postIds, userId)` method that batch-loads polls + options + user vote status for multiple post IDs in one query

**Server routes** — In `GET /posts` and `GET /posts/pinned`: after fetching posts, call `findByPostIds` and attach `poll` data to each post object

**PostCard** — Add `<PollCard poll={post.poll} postId={post.id} />` after the body, only when `post.poll` exists

**New component** `apps/community/src/components/PollCard.jsx` — Compact poll component that:
- Shows question
- Shows options with vote bars (with user's vote highlighted)
- Shows total vote count
- Clicking the card or vote button navigates to the post detail page
- Works as a read-only preview in the card context

**CSS** — Add compact poll styles to `community.css`
